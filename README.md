Neon Coast Cover Studio — a browser app that turns any photo into GTA-style cover art: multi-panel layouts, a giant gradient title overlapping the panel seams, a neon script line, colour grades, per-panel crop and position, and PNG export in 1920×1080, 1080×1080 and 1080×1350. Runs fully offline from its own files.

## Run it

```sh
node serve.ts
```
