Leonida Nights is a GTA-style cover art maker: load your own photos (or the five original sample scenes), pan and zoom each panel, edit the title and tagline, and export a multi-panel Vice City sunset poster as a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Every face stays fully visible — the title lives in its own band below the hero photo, the tagline sits inside that band, and each panel label sits in a solid strip below its photo, so no text ever covers a face.

## Run it

```sh
python3 -m http.server --directory app 8080
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests, fully offline static files.
